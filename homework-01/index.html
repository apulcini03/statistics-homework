Theoretical Background

Elliptic Curve Cryptography

Elliptic Curve Cryptography (ECC) is a form of public-key cryptography based on mathematical operations involving points on elliptic curves over finite fields.

A private key is an integer k, while the public key is a point Q obtained through elliptic-curve scalar multiplication:

Q = kG

Here, G is a publicly known base point. Scalar multiplication consists of repeatedly adding G to itself according to the elliptic curve point-addition rules.

The Toy Elliptic Curve

This application uses the curve:

y² = x³ + 7 (mod 17)

The base point is G = (1, 5). Since computations are performed modulo 17, the coordinates belong to the finite field F17.

The point G has order 9, meaning that 9G = O, where O is the point at infinity. Therefore, the generated points repeat every nine scalar multiplications.

The One-Way Property

Computing Q = kG is efficient, while recovering k from Q is computationally difficult for appropriately chosen cryptographic curves and sufficiently large parameters. This is known as the Elliptic Curve Discrete Logarithm Problem (ECDLP).

Our toy curve is not cryptographically secure: its small subgroup makes it easy to recover the private key by testing possible values.

Connection to Ethereum

Ethereum uses the secp256k1 elliptic curve for its traditional externally owned account signature scheme. Its equation has the same general form: y² = x³ + 7, but calculations are performed over a much larger finite field.

This application demonstrates the underlying scalar multiplication principle, without implementing real Ethereum cryptography, addresses or digital signatures.
