Theoretical Background

Definite Integration

Integration is used to calculate accumulated quantities, areas and expectations of random variables.

Riemann and Lebesgue integration provide different constructions of the integral.

For sufficiently regular functions, both approaches produce the same value. However, Lebesgue integration applies to a broader class of functions.

Riemann Integration

Riemann integration partitions the domain [a,b] into subintervals.

A sample point is selected in each subinterval, and the function value is multiplied by the interval width.

The resulting Riemann sums approximate the integral as the partition becomes increasingly fine.

Riemann sum: sum f(x_i*) * Delta_x_i

Numerical quadrature methods, including left, right and midpoint rules, are based on this principle.

Lebesgue Integration

Lebesgue integration is based on measuring sets of points where a function takes specified values or belongs to a given range.

Instead of partitioning only the domain, we can divide the range of function values into levels.

Each level corresponds to a measurable preimage in the domain. Its contribution depends on the measure of that preimage.

Non-negative measurable functions can be approximated from below using simple functions.

Integral of a simple function: sum c_j * measure(A_j)

Here, c_j is a function level and A_j is its associated measurable set.

Numerical Approximation vs Mathematical Definition

Numerical sampling provides only finite information about a function. It cannot, by itself, determine the exact measure of every preimage.

This distinction becomes essential for pathological functions, especially those whose behavior differs on rational and irrational points.

The experiments will distinguish numerical approximations from mathematically established results.

The Standard Normal Distribution

The standard normal distribution has mean zero and variance one.

Its probability density function is:

phi(x) = exp(-x²/2) / sqrt(2*pi)

Its cumulative distribution function gives the probability that a standard normal random variable is less than or equal to x:

Phi(x) = integral from -infinity to x of phi(t) dt

The normal CDF has no elementary closed-form expression, but it can be represented exactly using the special function erf.

Step 4 — Pathological Functions

The Dirichlet function equals one at rational points and zero at irrational points.

It is Lebesgue-integrable with integral zero because the rational numbers have Lebesgue measure zero.

It is not Riemann-integrable: every interval contains both rational and irrational numbers, so upper and lower Darboux sums cannot converge to the same value.

Thomae's function equals 1/q at a rational number p/q in lowest terms and zero at irrational points.

It is Riemann-integrable with integral zero, despite being discontinuous at every rational point.

These functions will be studied using mathematical properties and carefully designed numerical examples, rather than relying on floating-point rationality tests.

Exercise 2 — Numerical Computation of the Normal CDF

Mathematical Definition

Let Z be a standard normal random variable, Z ~ N(0,1).

The cumulative distribution function is:

Phi(x) = P(Z <= x)

Phi(x) = (1/sqrt(2*pi)) * integral from -infinity to x of exp(-t²/2) dt

Step 3 — Error Function

The error function provides an exact representation of the normal CDF:

Phi(x) = 0.5 * [1 + erf(x / sqrt(2))]

This is an exact mathematical relationship, although evaluating erf numerically still requires a computational algorithm.

Liouville's Theorem and Special Functions

The Gaussian density does not have an elementary antiderivative.

Liouville's theorem on elementary integration provides the mathematical framework for proving this fact.

Introducing the error function extends the available analytical language and allows the CDF to be expressed exactly.

However, an exact expression in terms of a special function is not the same as an elementary numerical evaluation algorithm.

Numerical methods remain essential when actual probability values must be computed efficiently.
