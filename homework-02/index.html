Assignment

Explore the cryptographic pipeline used in Ethereum wallets, from a mnemonic phrase to a checksummed Ethereum address.

Theoretical Background

BIP-39, BIP-32, BIP-44, secp256k1, Keccak-256 and EIP-55.

Interactive Wallet Pipeline

Step 1 — BIP-39: Mnemonic to Seed

Convert a public test mnemonic into a 512-bit seed using PBKDF2-HMAC-SHA512.

Step 2 — BIP-32 / BIP-44: Private Key Derivation

Derive an Ethereum private key from the BIP-39 seed using a hierarchical deterministic wallet.

Derivation Path: m/44'/60'/0'/0/0

Step 3 — secp256k1: Public Key Generation

Generate the public key Q = kG from the derived private key using the secp256k1 elliptic curve.

Step 4 — Keccak-256: Ethereum Address Derivation

Hash the 64-byte public key coordinates (without the 04 prefix) using Keccak-256, then take the last 20 bytes of the hash.

Step 5 — EIP-55: Checksummed Address

Apply EIP-55 mixed-case checksum encoding to the Ethereum address. The underlying 20-byte address remains unchanged.
